## Key Features
- **XIAO nRF52840**
- **Rotary Encoder**
- **Hotswapable Keys**

## Description
A small 32 key split keyboard with thumb knobs that can be powered wired or wirelessly.

## Components
- 2 XIAO nRF52840
- 2 Rotary Encoders
- 32 Hotswap Keys
- 32 Diodes
